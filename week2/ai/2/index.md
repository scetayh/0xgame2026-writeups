# 还有更优解吗？

根据多次尝试，24 轮攻击（原为 52 轮）的手段主要分为四大类：

- 直接复述/提取
- 变换 secret 的字面（方式最多）
- 用户伪装身份或用户赋予模型身份（心理学/社会学方向）
- 第一轮诱导，第二轮提取 secret（语言方向）

防御思路是“概括应当拒绝的行为+足量列举”。先用搓一个几百字的提示词，然后每次失败后逐一添加列举项，直到通过测试，然后缩短词句。
